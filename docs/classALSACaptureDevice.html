Detailed Description

ALSA capture device with callback. Samples are of type int16_t and are interleaved in the buffer for stereo.

Member Typedef Documentation

◆ OnPeriod

using ALSACaptureDevice::OnPeriod = std::function<void (const std::vector<int16_t> &)>

Callback type which returns a period with frames inside. For mono it's simply a stream of int16. For stereo they are interleaved: LRLRLR etc.

Starts audio capture of the ALSA device with the requested paramters. If this method is successful on return it will start calling the callback at the rate of the period.

Parameters
_device_nameALSA device as listed for example by "arecord -l".
_sample_rateRequested exact sampling rate of the device. No deviation is allowed.
_channelsRequested exact number of channels. No deviation is allowed.
_frames_per_periodDesired number of frames per period. This might be chnanged by ALSA.
Returns
Is true on success. False if any of the parameters won't work.
